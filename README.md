This repo contains the code for backend done with fastapi and frontend developed in streamlit. the whole thing is to retrieve info about earthquakes from https://earthquake.usgs.gov and display location of earthwakes on a world-view map given a start date and an end date. 


**Steps to run the app**

- [Install uv](https://docs.astral.sh/uv/getting-started/installation/)
- start backend with ```make backend```
- start frontend with ```make frontend```
